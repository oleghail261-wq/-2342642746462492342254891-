# ТВ Пульт: перебор ИК-кодов

Android-приложение, которое включает телевизор, перебирая коды кнопки питания
через встроенный ИК-передатчик телефона (Xiaomi / Redmi / POCO, Huawei, Honor и др.).

## Возможности
- База из ~450 уникальных кодов питания (Samsung, LG, Sony, Philips, Panasonic, Toshiba,
  Sharp, TCL, Thomson, Grundig, Hitachi, JVC, Sanyo, Akai, Daewoo и многие другие).
  Сначала идут самые популярные марки и «дискретные» коды включения.
- 18 ИК-протоколов: NEC, NECx (Samsung), RC5, RC6 (Philips), Sony SIRC 12/15/20,
  JVC, Panasonic (Kaseikyo), Sharp, RCA, Mitsubishi, Proton, Aiwa, Pioneer, Emerson и др.
- Выбор марки, настройка паузы между кодами, перебор по кругу.
- После остановки — ручной режим «◀ Назад / Отправить / Вперёд ▶», чтобы точно найти
  сработавший код, и кнопка «Запомнить» — дальше приложение работает как обычный пульт ВКЛ/ВЫКЛ.

## Как получить APK
Каждый push собирает APK в GitHub Actions. Готовый файл `TvPowerIR.apk` лежит в
разделе **Releases** репозитория (и в артефактах сборки во вкладке **Actions**).

Локальная сборка: Android SDK + `gradle assembleRelease`.

## Использование
1. Установите APK, разрешив установку из неизвестных источников.
2. Направьте верх телефона (ИК-окошко) на телевизор с 1–3 м.
3. Выберите марку (или «Все бренды») и нажмите **СТАРТ**.
4. Когда ТВ включится — сразу **СТОП**, затем кнопкой «◀ Назад» и «Отправить»
   найдите точный код и нажмите **Запомнить**.

Источник кодов: база [IRDB](https://github.com/probonopd/irdb) + известные коды популярных марок.
